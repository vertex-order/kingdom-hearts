# Kingdom Hearts: Chain of Memories ~Manga~

## Editions (ISBN)

Per-book record, one book per label. See sources/kingdom-hearts-manga-2003.md
for the fuller pattern. Single content edition (no "Re:Chain of Memories"
alt release) -- publisher/date/page count dropped from most labels below
since there's nothing content-differentiated to track; kept only where a
Panini ASIN-only print has no ISBN/format to identify it by otherwise, or
where Volume 2/the box set had an explicit Format given. Goal per
docs/sources.md is language discovery, not a full print catalog -- extra
same-language prints (2nd/3rd/4th Italian, 2nd Spanish, library-binding
English) are recorded here but not promoted to the entry's `languages[]`
link once a language's already covered.
